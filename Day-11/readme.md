# Day 11 — Strings in Java

Today I learned about **Strings in Java**, how to declare and manipulate strings, compare them, extract substrings, and understand String immutability.

## Topics Covered

1. Introduction to Strings
2. String declaration and initialization
3. Taking String input using `Scanner`
4. Difference between `next()` and `nextLine()`
5. String concatenation using `+`
6. Finding String length using `length()`
7. Accessing characters using `charAt()`
8. Comparing Strings using `compareTo()`
9. Difference between `==` and `.equals()`
10. Extracting substrings using `substring()`
11. String immutability

## Practice

- Take a full name as input and print it.
- Count the number of characters in a String.
- Print each character of a String using a loop.
- Compare two Strings using `equals()`.
- Extract the first four characters of a String.
- Count the number of vowels in a String.
- Reverse a String using a loop.
- Check whether a String is a palindrome.

## Key Learnings

- `String` is a reference type in Java.
- `next()` reads a token, while `nextLine()` reads a line.
- `+` joins Strings.
- `length()` returns the number of characters.
- `charAt()` accesses a character by index.
- `equals()` compares String contents.
- `==` compares references for String objects.
- `compareTo()` performs lexicographic comparison.
- `substring(start, end)` excludes the ending index.
- Strings are immutable.
