## Key Learning

Methods help us avoid writing the same code repeatedly.
Instead of :
```text
Write code
Write same code again
Write same code again
```
We can :
```text
Create Method
     ↓
Call Method whenever needed
```
This makes programs more organized, reusable, and easier to maintain.
