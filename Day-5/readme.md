## Key Learning

The most important concept I learned today is how to analyze the relationship between rows and columns before writing nested loops.

For pattern problems:
```text
Rows → Outer Loop
Columns → Inner Loop
Pattern Logic → Conditions / Counters
```

Understanding the number of rows, number of columns, spaces characters, and their relationship helps in designing the correctloop structure.
