* Find the largest element in an Array.
* Find the smallest element in an Array.
* Search for an element using Linear Search.
* Count how many times a particular element occurs.
* Calculate the sum and average of Array elements.

## Key Learning

* Arrays store multiple values of the same data type.
* Array indexing starts from 0.
* The last index is length - 1.
* Java automatically initializes Array elements with default values.
* .length gives the size of an Array.
* for loops are commonly used to traverse Arrays.
* Linear Search checks elements one by one.
* Linear Search has O(n) time complexity in the worst case.
