# Day 10 — 2D Arrays

Today I learned about **2D Arrays in Java**, how they are represented as rows and columns, how to take input/output using nested loops, and how to search for an element and find its coordinates.

## Topics Covered

1. Introduction to 2D Arrays
2. 2D Arrays as a matrix/grid
3. Rows and Columns
4. Row and Column indexing
5. Zero-based indexing
6. Declaration and initialization of 2D Arrays
7. Memory allocation
8. Taking input using nested loops
9. Printing 2D Arrays using nested loops
10. Searching an element in a 2D Array
11. Finding row and column coordinates

## Practice

* Find the largest element in a 2D Array.
* Find the smallest element in a 2D Array.
* Search for an element and print its coordinates.
* Calculate the sum of all elements.
* Calculate the sum of each row.
* Calculate the sum of each column.

## Key Learning

* A 2D Array stores data using rows and columns.
* Both row and column indexing start from `0`.
* 2D Arrays use the syntax `array[row][column]`.
* Nested loops are commonly used to traverse 2D Arrays.
* `array.length` gives the number of rows.
* `matrix[i].length` gives the number of columns in row `i`.
* Searching every element in a 2D Array takes `O(rows × columns)`.
* A Java 2D Array is technically an array of arrays.
