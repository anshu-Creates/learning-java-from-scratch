## Key Learning

The main goal of complexity analysis is to understand how efficiently an algorithm performs as the input size increases.

An algorithm that works well for a small input may become inefficient when the input becomes very large.
```text
Input Size increases
        ↓
Number of Operations increases
        ↓
Analyze Time Complexity
```
Similarly :
```text
Input Size increases
        ↓
Memory Requirements increase
        ↓
Analyze Space Complexity
```
