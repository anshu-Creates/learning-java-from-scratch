## Key Learning

Today's main focus was understanding the mathematical relationship between the row number and the required output.

For example:
```text
Row number → i

Spaces → n - i

Middle spaces → 2 * (n - i)

Stars in diamond → 2 * i - 1
```
Instead of randomly changing loop conditions, I learned to first analyze the pattern and find the relationship between rows, spaces, stars, and numbers.
